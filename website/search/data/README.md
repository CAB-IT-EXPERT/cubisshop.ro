# Date de căutare Cubis Shop

Acest director nu conține datele sau indexurile copiate de la G-Trots.

Fișierele de căutare se regenerează numai după ce sursa este conectată la baza
`cabitro_cubisshop.ro`. Generatorul diagnostic refuză pornirea fără variabila
`CUBIS_DIAGNOSTIC_API_URL` și acceptă numai `cubisshop.ro` sau localhost.
