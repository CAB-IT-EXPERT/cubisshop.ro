# Cubis Shop — informații pentru agenți

## Stare curentă

Cubis Shop este în etapa de izolare tehnică. Identitatea juridică, datele de contact, produsele, categoriile, stocurile și conținutul diagnostic vor fi publicate numai după configurarea bazei `cabitro_cubisshop.ro`.

Nu folosiți informații despre produse, prețuri, stocuri, companie sau service provenite din G-Trots. În această copie nu există încă un catalog Cubis Shop publicat.

## Surse Cubis Shop

- Website: https://cubisshop.ro/
- Magazin: https://cubisshop.ro/magazin
- API public planificat: https://cubisshop.ro/shop-api/
- Sitemap curent: https://cubisshop.ro/sitemap.xml
- Reguli pentru roboți: https://cubisshop.ro/robots.txt

Paginile de produs, sitemapul de produse, catalogul JSON și feedurile se vor genera exclusiv din viitoarea bază Cubis Shop. Absența lor în această etapă este intenționată.

## Integrări

Google Analytics, Google Customer Reviews, Search Console și Google Identity sunt dezactivate până la configurarea identificatorilor Cubis Shop. Google Merchant Center, Shopify Catalog și integrările Meta de tracking/catalog au fost eliminate. Stripe este permis numai în modul TEST.
